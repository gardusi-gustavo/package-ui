# package-ui

Pure HTML + CSS design-system registry. No JavaScript or TypeScript.

## Layout

| `src/html/` | structural partials |
| `src/css/` | tokens, reset, layout, components |
| `examples/` | static gallery |

## Validation

```bash
bash infra/scripts/ci.sh
```

## Rules

- Public contract/asset package only.
- No application data, secrets, or personal data.
- Versioned by tag.
